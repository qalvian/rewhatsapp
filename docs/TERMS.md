## 2. Description of the Service
rewhatsapp is a client-side personal memory replayer that parses text-based WhatsApp export files (`.txt` generated via WhatsApp's &ldquo;Without Media&rdquo; export feature) entirely within the user's browser memory to simulate an animated chat timeline.

The Application currently does not support compressed archive formats (`.zip`) or attached multimedia files (such as photographs, videos, audio notes, or documents). The Application is not a chat backup solution, communication messenger, investigative utility, or cloud storage platform.
