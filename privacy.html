Privacy Policy

Executive Summary

rewhatsapp is architected as an exclusively client-side software application. The service does not operate remote database systems, server-side processing pipelines, network telemetry, analytics trackers, or persistent cloud infrastructure. All data parsing, chronological sequencing, and local audio synthesis execute strictly within the volatile memory (RAM) of the user's web browser environment. Once the web application is loaded, the user may disconnect network connectivity or engage Airplane Mode; all operations remain fully functional offline.

1. Summary & Scope

This Privacy Policy governs the use of the web application known as rewhatsapp (“the Application”, “the Service”, “we”, “us”), published and maintained by qalvian (“the Maintainer”). This Policy outlines the technical architecture, data handling practices, and legal framework applicable to user interactions with the Application.

This Policy applies exclusively to interactions with the rewhatsapp website. rewhatsapp is an independent, non-commercial open-source software project. The Application is neither affiliated with, sponsored by, endorsed by, nor operated by WhatsApp LLC, Meta Platforms, Inc., or any of their corporate affiliates.

2. Zero-Server Processing and Data Fiduciary Status

The Application does not collect, transmit, store, inspect, or retain user communications, exported conversation archives, or contact identifiers.

All parsing of exported WhatsApp conversations occurs entirely on the user's physical device for personal and non-commercial viewing. Because the Maintainer does not determine the purpose or means of processing personal data on remote servers, and exercises neither control nor access over conversation content, the Maintainer does not act as a “Data Fiduciary” or “Data Processor” within the meaning of the Digital Personal Data Protection Act, 2023 (DPDPA 2023) with respect to conversation contents.

Technical Note: This statement reflects the technical architecture of client-side computing and is provided for operational transparency, rather than as a contractual warranty.

3. Data Not Collected

To eliminate any ambiguity, rewhatsapp does not collect, record, log, or transmit any of the following categories of data:

  • Conversation Messages & Content: Text strings, message timestamps, emoji reactions, and continuity segments remain confined exclusively to local volatile memory.
  • Participant Information: Telephone numbers, contact names, and profile monograms extracted from export files exist solely in runtime memory during an active session.
  • Export Format Scope: The Application currently processes plain-text export files (.txt created via WhatsApp's “Without Media” option). Compressed archives (.zip) and multimedia assets (photographs, voice notes, video clips, and document attachments) are not supported.
  • Device & Telemetry Identifiers: No device fingerprints, browser canvas fingerprints, advertising identifiers, or analytical beacons are generated or monitored.
  • Application-Level Connection Logs: The client application does not generate or retain network access logs.
  • Third-Party Cookies & Trackers: Zero advertising tags, third-party trackers, or marketing cookies are loaded.

4. Local Browser Storage Disclosure

The Application utilizes the browser's standard localStorage API solely to persist optional interface preferences across browser sessions. The Application does not deploy HTTP cookies.

  • rewhatsapp_speed: Stores the selected playback multiplier (e.g., 1×, 2×, 4×).
  • rewhatsapp_muted: Stores the binary sound preference (true / false).
  • rewhatsapp_volume: Stores the Web Audio output gain level (0.0 to 1.0).
  • rewhatsapp_legal_consent_v1: Records user acknowledgement of these Terms and Privacy Policy (true).

Clearing Local Preferences: Users may purge stored preference keys at any time by using the “Clear stored preferences” control on the homepage or through browser configuration settings (Settings → Privacy & Security → Clear Browsing Data → Cookies and Site Data).

5. Static Hosting Infrastructure

The static application assets (HTML, CSS, and client-side JavaScript) are distributed via GitHub Pages (operated by GitHub, Inc.).

When a web browser requests static assets from the hosting delivery network, the underlying web servers may automatically log standard transmission metadata (such as public IP address, HTTP referer, request timestamp, and browser user-agent header). Such server logs are captured directly by the infrastructure hosting provider under its respective privacy practices and fall outside our operational control.

6. Third-Party Information in Conversation Exports

WhatsApp conversation exports inherently contain communications and personal identifiers belonging to third parties (including friends, family members, colleagues, or group chat participants).

The user bears sole legal responsibility for ensuring lawful authorization to process exported conversations. Users must refrain from processing conversation exports without lawful entitlement or appropriate consent from participating parties, and must restrict usage to lawful, personal, and private reminiscence.

7. Age Eligibility

The Application is intended for individuals aged 18 years or older. Individuals under the age of 18 may access the Application solely under the supervision of a parent or lawful legal guardian. Because the Application operates strictly client-side without remote data retention, no personal information from minors is knowingly solicited, collected, or stored.

8. Technical Security Architecture

Privacy protection is enforced directly through technological architectural controls:

  • Content Security Policy (CSP): The HTTP CSP specification declares default-src 'none'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self'; connect-src 'self';, ensuring that the browser engine forcibly disallows outbound data transmissions to external hosts.
  • Sandboxed Execution Contexts: Parsing routines execute within origin-restricted threads without access to external networking APIs.
  • Open-Source Auditing: The complete source code is publicly accessible on GitHub, permitting independent inspection and verification by security practitioners and users.

9. Statutory Rights under the Digital Personal Data Protection Act, 2023

The Digital Personal Data Protection Act, 2023 (DPDPA 2023) guarantees data principals specific rights concerning personal data held by data fiduciaries, including rights of access, correction, erasure, and grievance redressal.

Because rewhatsapp maintains no centralized databases, retains zero communication logs, and operates no user account management, the Maintainer possesses no records against which access, rectification, or erasure requests can be executed. Terminating the browser session immediately and irreversibly purges all conversation data from physical device memory.
